These files preserve work recovered from the earlier Fremont Digital conversation. They are reference material, not the current site or an approved design.

- `fremont-digital-website.zip`: original V1 website.
- `fremont-digital-website-v2.zip`: original V2 website.
- `PROJECT-HANDOFF.md` and `CODEX-IMPLEMENTATION-BRIEF.md`: the earlier handoff.

The owner subsequently chose a broader range of technology services, removed the portfolio/concept-gallery direction, supplied the refined logo files, and requested a component-by-component workflow beginning with the favicon. Read the root `PROJECT-DECISIONS.md` for the current direction.

Rejected artwork and unused explorations are kept only locally and excluded from Git.
